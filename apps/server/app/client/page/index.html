Welcome to the Dooto API

The Dooto API is the core backend service that powers the Dooto Todo App. It provides a fast and reliable way to manage tasks, daily goals, and user profiles.

View API Endpoints

Base URL

https://api.dooto.app

🧩 Current Endpoints

These endpoints are available in the current version of the Dooto API.

GET /todos

Retrieve all todos for the authenticated user.

POST /todos

Create a new todo item.

PUT /todos/:id

Update a specific todo item.

DELETE /todos/:id

Remove a todo item.

GET /daily-todo

Retrieve the user’s daily todo list.

POST /daily-todo

Add a new daily todo item.

GET /profile

Fetch the user’s profile details.

PUT /profile

Update profile information such as name, bio, or preferences.
